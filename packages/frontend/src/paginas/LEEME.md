# paginas/ · Páginas

Las 34 pantallas. Cada archivo empieza con un comentario: ruta, quién la ve, qué muestra y cómo modificarla.

Carpetas: `publico`, `acceso`, `sistema`, `compartidas` (Mensajes), `colaboradora`, `organizacion`, `admin` (equipo administrativo, rol `adm`: se entra con admin@demo.org). `auxiliares.js` guarda lo que comparten varias pantallas de una carpeta.
